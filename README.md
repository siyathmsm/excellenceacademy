# Excellence Academy Website

A responsive, premium one-page website built with HTML5, CSS3, and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — responsive design, themes, and animations
- `script.js` — navigation, filters, sliders, counters, particles, FAQ, Mentora demo AI assistant
- `assets/excellence-academy-logo.png` — supplied academy logo

## Open the website

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For deployment, upload the complete folder to your hosting provider.

## Form setup

The enquiry and newsletter forms currently demonstrate the interface only. Connect them to:

- your own backend/API,
- Formspree,
- Netlify Forms,
- Firebase,
- Supabase,
- or another form service.

## Images and icons

The layout uses remote Unsplash images and Font Awesome/Google Fonts CDNs. Internet access is needed for those assets. The academy logo is included locally.
